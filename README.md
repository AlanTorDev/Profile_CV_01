# Tam Minh Hoang — Cinematic Developer CV

A cinematic, editorial-style developer portfolio with a restrained system-interface layer. Built with vanilla HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. The `resume.pdf` link opens the included `Tam-Minh-Hoang-Resume-EN.pdf`.

No build step or package installation is required. Google Fonts are loaded online; fallback fonts are included.

## Features
- Oversized editorial hero with system status monitor
- Charcoal/black palette with restrained acid-lime accents
- Dark/light theme toggle with saved preference
- Responsive desktop navigation and mobile menu
- Experience timeline with dates, durations and measurable achievements
- Project showcases, skills, education and contact sections
- Scroll progress, section navigation, reveal animation, subtle status monitor parallax
- Reduced-motion support and keyboard Escape to close the mobile menu

## Customize
- Edit text/content in `index.html`.
- Change colors, spacing and breakpoints in `styles.css`.
- Interaction logic is in `script.js`.
- Update `Tam-Minh-Hoang-Resume-EN.pdf` if you replace your resume.

Note: the status monitor uses a stylized TMH core instead of a fabricated portrait. The social links are placeholders and should be updated to your actual profiles.
